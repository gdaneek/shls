class EventPublisher

Доставляет события outbox в отдельном потоке и удаляет их после подтверждения брокера.

Читает события по sequence, повторяет инвалидацию кеша и отправляет persistent-сообщения в кворумную очередь. Строка outbox удаляется после ACK брокера.

Примечание

Рассчитан на одного издателя для общей таблицы outbox. Сбой между подтверждением публикации и удалением строки может привести к повторной доставке.

Public Functions

EventPublisher(Config config, drogon::orm::DbClientPtr db, drogon::nosql::RedisClientPtr redis)

Задаёт настройки брокера и клиенты хранилищ без запуска потока.

Примечание

Подключение к брокеру выполняется после Start(), а не в конструкторе.

Параметры:

  • config – [in] Настройки подключения и имя кворумной очереди.

  • db – [in] Ненулевой клиент PostgreSQL с доступом к outbox_events.

  • redis – [in] Клиент Redis для инвалидации кеша; может быть nullptr.

~EventPublisher()

Останавливает поток и ждёт его завершения, оставляя недоставленные события в outbox.

Примечание

Прерывает ожидание повтора, но не текущую блокирующую операцию. Не пытается опустошить outbox; не должен вызываться из потока издателя.

void Start()

Запускает поток публикации; вызывается один раз после создания схемы.

Примечание

Возвращается без ожидания подключения к RabbitMQ или доставки событий. Повторный вызов для работающего потока недопустим.

Бросает исключение:

std::system_error – Если операционная система не смогла создать поток.

Pre:

Таблица outbox_events создана; поток ещё не запускался.

Private Functions

void Run()

Публикует outbox по порядку, повторяя неудачные попытки до остановки.

При отсутствии событий или ошибке делает паузу перед следующим чтением. После запроса остановки закрывает соединение.

Примечание

Ошибка инвалидации Redis не блокирует публикацию. SQL-ошибки и ошибки доставки оставляют событие в outbox для следующей попытки.

bool Connect()

Подключается к следующему брокеру и настраивает очередь и подтверждения.

Примечание

Одна попытка проверяет один адрес. Следующая попытка использует следующий адрес списка; при ошибке созданное соединение освобождается.

Pre:

Активного соединения нет; вызывается только из потока издателя.

Результат:

true при готовности соединения, очереди и publisher confirms; false при ошибке подключения, входа или настройки.

void Disconnect()

Освобождает текущее AMQP-соединение, если оно существует.

Примечание

Вызывается из потока издателя; повторный вызов безопасен. Не удаляет очередь брокера и строки outbox.

bool Send(const Message &message)

Публикует сохраняемое событие и возвращает признак подтверждения брокером.

Примечание

Использует обменник по умолчанию и имя очереди как ключ маршрутизации. Подтверждение брокера не означает обработку потребителем; false не исключает фактическую доставку, если подтверждение было потеряно.

Параметры:

message – [in] Событие с типом, постоянным идентификатором и JSON-телом.

Pre:

Connect() успешно завершён; вызов выполняется из потока издателя.

Результат:

true только после ACK брокера; false при ошибке, таймауте или NACK.

void WaitBeforeRetry()

Ждёт окончания задержки перед повтором или уведомления об остановке.

Примечание

Ожидает до одной секунды с проверкой флага stopping_. Условная переменная позволяет деструктору прервать паузу без ожидания всего интервала.
