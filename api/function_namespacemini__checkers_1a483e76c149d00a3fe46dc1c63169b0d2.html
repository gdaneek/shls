int mini_checkers::CellIndex(Cell cell)

Преобразует координаты в построчный индекс без проверки границ.

Параметры:

cell – [in] Координаты клетки.

Pre:

Обе координаты находятся в диапазоне 0–7.

Результат:

Индекс row * 8 + col в диапазоне 0–63.
