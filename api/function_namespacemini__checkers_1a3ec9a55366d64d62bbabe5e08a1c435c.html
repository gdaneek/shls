Function Documentation

MoveResult mini_checkers::ApplyMove(Position position, Cell from, Cell to)

Применяет участок хода, превращает шашку в дамку и определяет завершение партии.

Примечание

Превращение действует немедленно, в том числе внутри цепочки боя. Очередь меняется и побитые фигуры снимаются только после завершения хода. Победитель определяется по отсутствию допустимых ходов у соперника.

Параметры:

  • position – [in] Исходная позиция, передаваемая по значению.

  • from – [in] Исходная клетка ходящей фигуры.

  • to – [in] Клетка назначения.

Бросает исключение:

std::invalid_argument – Если ход недопустим.

Результат:

Новая позиция, сведения о взятии и превращении, возможный победитель.

Pre:

Индексы уже побитых фигур в position.captured корректны.
