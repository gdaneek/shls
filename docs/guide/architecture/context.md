# Контекст системы — C1

Mini Checkers — приложение для двух игроков. Первый игрок создаёт
партию, второй присоединяется, после чего они ходят по очереди. Зритель может
читать состояние, не занимая сторону.

```{graphviz} ../_static/context.dot
:alt: Контекст: игроки и зритель взаимодействуют с системой Mini Checkers
```

Это граница всей системы: на схеме не раскрыто, какие контейнеры выполняют
запрос. Клиентом может быть браузер или другой HTTP-клиент. При обычном
локальном запуске входной порт опубликован только на `127.0.0.1` хоста.

Для изменения партии участник использует свой секретный токен, выданный при
создании или присоединении. UUID идентифицирует партию, но сам по себе не
даёт права ходить. Отдельной регистрации пользователей в проекте нет.
