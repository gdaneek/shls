# Mini Checkers

[![CI](https://github.com/gdaneek/shls-project/actions/workflows/ci.yml/badge.svg?branch=dev)](https://github.com/gdaneek/shls-project/actions/workflows/ci.yml?query=branch%3Adev)

Mini Checkers — веб-приложение для игры в шашки вдвоём.

## Возможности

- Создание партии и подключение соперника по её ID.
- Обязательные взятия, цепочки взятий, дамки и автоматическое определение победителя.
- Режим зрителя и автоматическое обновление доски.
- Сохранение партий и резервное копирование данных.

## Сборка и запуск

Для приведённых команд нужны Linux, Docker Engine с Docker Compose v2, `nftables`, `sudo` и `openssl`. Все зависимости приложения и C++-код собираются внутри Docker — устанавливать компилятор отдельно не нужно.

Из корня репозитория:

1. Создайте конфигурацию, **только если `.env` ещё нет**:

   ```bash
   cp .env.example .env
   chmod 600 .env
   ```

2. Откройте `.env` и замените значения-заглушки:
   - `POSTGRES_PASSWORD` и `RABBITMQ_PASSWORD` — свои пароли;
   - `POSTGRES_REPLICATION_PASSWORD` и `RABBITMQ_ERLANG_COOKIE` — для каждого сгенерируйте отдельное значение командой `openssl rand -hex 32`.

3. Соберите и запустите приложение:

   ```bash
   infra/firewall/firewall.sh apply
   docker compose up --build -d --wait --wait-timeout 240
   ```

   Первая сборка может занять несколько минут. После перезагрузки компьютера правила firewall нужно применить заново.

4. Откройте **http://127.0.0.1:8000/**. Другой порт можно задать через `API_PORT` в `.env`.

Если обновляете старую установку с одним RabbitMQ, вместо обычного запуска используйте `scripts/upgrade-rabbitmq.sh`. Существующий `.env` не перезаписывайте и тома не удаляйте.

## Как играть

1. Нажмите **«Создать игру»** — вы играете белыми. Скопируйте ID партии.
2. Нажмите **«Вторая вкладка»**, вставьте ID и выберите **«Присоединиться»** — это чёрные. Для игры с другим человеком передайте ему ID; сайт по умолчанию доступен только с вашего компьютера.
3. Выберите шашку и затем подсвеченную клетку. Подключение соперника и ходы появляются автоматически; при необходимости нажмите **«Обновить»**.
4. **«Сдаться»** завершает партию. **«Смотреть»** открывает игру без занятия места.

Ключ игрока хранится только в своей вкладке и переживает её перезагрузку. Не закрывайте вкладку до конца игры; для второго игрока используйте «Вторая вкладка», а не дублирование первой.

Взятие обязательно в обе стороны. Продолжайте бой той же шашкой, пока есть взятия. На последнем ряду шашка становится дамкой (Д), в том числе во время боя; дамка ходит и бьёт по всей диагонали. Побитые фигуры отмечаются крестиком и снимаются после всей цепочки. Победа определяется автоматически, когда у соперника нет фигур или ходов. Часы и спортивные правила ничьих не реализованы.

Если VPN блокирует доступ к сайту, разрешите локальную сеть в его настройках или временно отключите VPN.

## Управление приложением

```bash
docker compose ps          # состояние компонентов
docker compose logs -f     # просмотр журналов; Ctrl+C завершает просмотр
docker compose down        # остановка с сохранением данных
```

Для повторного запуска или пересборки используйте команду `docker compose up --build -d --wait --wait-timeout 240`. Не удаляйте Docker-тома, если хотите сохранить партии.

Проверки работающего стенда описаны в `scripts/integration/README.md`.

## Резервные копии

```bash
scripts/backup.sh                      # создать архив БД в backups/
scripts/restore.sh backups/<имя>.dump   # восстановить в новую тестовую БД
scripts/backup-timer.sh install        # ежедневный бэкап в 02:00, systemd user timer
scripts/backup-timer.sh remove         # отключить расписание
```

Архивы хранятся 7 дней. Восстановление создаёт отдельную проверочную БД и не заменяет рабочие партии. Для расписания нужен пользовательский `systemd`.
