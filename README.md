# Mini Checkers

Mini Checkers — небольшой онлайн-сервис для игры в упрощённые шашки вдвоём. Планируется реализовать создание игры, подключение второго игрока, поочерёдные ходы и сохранение состояния партии. Основная цель — не полноценный игровой движок, а демонстрация взаимодействия микросервисов и практик безопасной разработки.

Проект предполагает два сервиса на C++20: REST API на Drogon и отдельный обработчик игровых событий. PostgreSQL будет хранить состояние игр, Redis — кешировать данные, а RabbitMQ — передавать события для асинхронной обработки. Запуск через Docker Compose, сегментация сети с явными правилами межсетевого экрана, проверка восстановления после сбоев и резервное копирование базы данных входят в план реализации.

## Запуск

Нужны Docker Engine и Docker Compose v2. Из корня репозитория:

```bash
cp .env.example .env    # если .env ещё нет; задайте свои пароли
docker compose up --build --wait --wait-timeout 180
curl http://127.0.0.1:8000/hello    # {"message":"hello-world"}
bash scripts/test-startup.sh
```

Наружу публикуется только API на `127.0.0.1:${API_PORT:-8000}`. Остановка — `docker compose down`, удаление данных вместе с томами — `docker compose down -v`.
