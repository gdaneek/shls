# Mini Checkers

Mini Checkers — учебный проект по курсу «Безопасность высоконагруженных систем»: небольшой онлайн-сервис для игры в упрощённые шашки вдвоём. Планируется реализовать создание игры, подключение второго игрока, поочерёдные ходы и сохранение состояния партии. Основная цель — не полноценный игровой движок, а демонстрация взаимодействия микросервисов и практик безопасной разработки.

Проект предполагает два сервиса на C++20: REST API на Drogon и отдельный обработчик игровых событий. PostgreSQL будет хранить состояние игр, Redis — кешировать данные, а RabbitMQ — передавать события для асинхронной обработки. Запуск через Docker Compose, сегментация сети с явными правилами межсетевого экрана, проверка восстановления после сбоев и резервное копирование базы данных входят в план реализации.
